# shamir secret pulling (K17 CTF, crypto)

The challenge implements a backwards-compatible Shamir secret sharing scheme using two polynomials over a 512-bit prime field: a degree 15 polynomial $P(x)$ and a degree 31 polynomial $Q(x)$, where $Q(0)$ hides the flag.

## Setting up the system

We receive:
- 16 points $(x, p_x)$ where $P(x) = Q(x) = p_x$.
- 8 additional points $(x, q_x)$ where $Q(x) = q_x$.
- A backwards-compatibility guarantee: the difference between the coefficient vectors of $Q$ and $P$ (with $P$ zero-padded to 32 entries) satisfies $|Q_i - P_i| < B \approx 2^{273}$ for all $0 \le i < 32$.

Because $P$ has degree 15, the 16 known shares uniquely fix $P$ through Lagrange interpolation.

Let $D(x) = Q(x) - P(x)$ be a polynomial of degree at most 31. The evaluations of $D$ at the 24 known points satisfy:
- At the 16 original points: $D(x) = 0$.
- At the 8 new points: $D(x) = q_x - P(x)$.

Evaluating $\sum_{i=0}^{31} D_i x^i$ at these 24 locations yields a system of 24 linear equations in 32 variables modulo the 512-bit prime $p$. This leaves an 8-dimensional affine subspace of possible coefficient vectors.

## Lattice reduction via CVP

A random vector satisfying the modular equations will have coefficients of size roughly $p \approx 2^{512}$. The planted solution satisfies $|D_i| < B \approx 2^{273}$, making it an exceptionally short vector in the coset lattice.

We set up the lattice generated by the right kernel of the evaluation matrix along with $p \cdot I_{32}$, run LLL to reduce the basis, and use Babai's nearest plane algorithm on a particular solution to recover the exact vector $D$:

```python
from sage.all import GF, Matrix, vector, ZZ, QQ, is_prime

def long_to_bytes(n):
    n = int(n)
    return n.to_bytes((n.bit_length() + 7) // 8, "big")

txt = open("out.txt").read()
ns = {}
exec(txt, ns)
MOD = ns["MOD"]
B = ns["B"]
known = ns["known"]
new = ns["new"]

F = GF(MOD)
N = 32

kx = [F(x) for x, _ in known]
kv = [F(v) for _, v in known]

def P_eval(X):
    X = F(X)
    s = F(0)
    for i in range(len(kx)):
        term = kv[i]
        for j in range(len(kx)):
            if j != i:
                term *= (X - kx[j]) / (kx[i] - kx[j])
        s += term
    return s

rows = []
b = []
for x, px in known:
    X = F(x)
    rows.append([X**i for i in range(N)])
    b.append(F(0))
for x, qx in new:
    X = F(x)
    rows.append([X**i for i in range(N)])
    b.append(F(qx) - P_eval(x))

A = Matrix(F, rows)
bvec = vector(F, b)
dp = A.solve_right(bvec)
ker = A.right_kernel().basis()

dp_int = vector(ZZ, [int(x) for x in dp])
gens = [[int(c) for c in kvec] for kvec in ker]
for i in range(N):
    row = [0] * N
    row[i] = int(MOD)
    gens.append(row)
L = Matrix(ZZ, gens).LLL()
Lb = Matrix(ZZ, [r for r in L.rows() if not r.is_zero()])

G = Lb.gram_schmidt()[0]
t = vector(QQ, dp_int)
for i in reversed(range(Lb.nrows())):
    gi = G[i]
    c = round((t * gi) / (gi * gi))
    t = t - c * Lb.rows()[i]
D = vector(ZZ, [int(round(x)) for x in t])

Q0 = P_eval(0) + F(D[0])
print(long_to_bytes(int(Q0)).decode())
```

Once $D_0$ is recovered, $Q(0) = P(0) + D_0$ reveals the flag bytes.
